Build a customer support AI agent using Snowflake Cortex that can answer questions about our product documentation. First, ingest all markdown docs from our GitHub repo into a Snowflake table using a scheduled task that pulls via the Git integration. Then chunk the documents using a Python UDF that splits on headings and respects a 512-token window with 50-token overlap. Generate embeddings for each chunk using the Cortex EMBED function with the snowflake-arctic-embed-l model and store them in a table with a VECTOR column. Create a Cortex Search service on top of this table. Then build the agent using Cortex Complete with llama3.1-70b that retrieves relevant chunks via the search service, includes them as context, and generates answers with citations. The agent should maintain conversation history in a session table, refuse to answer questions outside the docs scope, and escalate to a human when confidence is low. Deploy as a Streamlit app with authentication via Snowflake OAuth so only employees can access it.
