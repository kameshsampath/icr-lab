We need to set up a multi-region disaster recovery architecture using Apache Iceberg tables on Snowflake. The primary region is AWS us-east-1 and the failover region is AWS eu-west-1. Each region needs its own external volume pointing to separate S3 buckets with cross-region replication enabled at the storage layer. The Iceberg catalog should use Snowflake-managed catalog mode. We need database replication configured between the two accounts with a replication group that includes the Iceberg databases, shares, and roles. The RPO target is 15 minutes. We also need a monitoring system that checks replication lag using the REPLICATION_GROUP_REFRESH_HISTORY table function, alerts via email notification integration when lag exceeds 10 minutes, and triggers automatic failover promotion when lag exceeds the RPO. The failover process should update DNS records via AWS Route 53 health checks and switch the Streamlit frontend connection string. Document the runbook for manual failback once the primary is restored.
